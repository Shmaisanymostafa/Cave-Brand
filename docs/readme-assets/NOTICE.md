# README artwork

`brand-overview.png` is a documentation composition of the repository's original English and Arabic full-colour SVG lockups and palette values. Logos are rendered without redrawing, recolouring, cropping or changing their proportions, on the approved white background.

Sources: `assets/logos/cave-logo-en-color-compact.svg`, `assets/logos/cave-logo-ar-color-compact.svg` and the palette in `index.html` at base commit `c48dff44191f63a6a4396bf03e3844da8e43e30f`.

The Cave marks retain the existing proprietary brand terms in the kit's `LICENSE.txt` and the brand guide. This composition grants no additional rights. No runtime assets or licences are changed.
